Supabase ops (maintainer)
=========================

Secrets (Dashboard → Project Settings → Edge Functions → Secrets)
-----------------------------------------------------------------
DISCORD_WEBHOOK_URL
  Full Discord channel webhook URL for notify-new-submission. Never commit to git.
  Rotate in Discord if the URL is exposed.

DISCORD_NOTIFY_USER_ID (required for @ push on mobile)
  Your numeric Discord user id (Developer Mode → right-click your name → Copy User ID).
  The bot prepends <@id> and sets allowed_mentions so webhook messages actually ping you.
  Plain @<username> in webhook text does not trigger notifications.

SITE_BASE_URL (optional)
  Default https://animelighthouses.github.io — used in Discord review links.

IMGUR_PROXY_BASE (recommended when moderating from the UK)
  e.g. https://anilist-imgur-proxy.animetoudaikikou.workers.dev — see
  docs/cloudflare-imgur-proxy-setup.md.

IMGUR_PROXY_KEY (recommended when moderating from the UK)
  Same secret as PROXY_SECRET on the Worker and IMGUR_PROXY_KEY in js/imgurProxy.js.
  Used by process-sighting-image when fetching i.imgur.com sourceUrl (avoids UK
  geo-block placeholders in Storage).

Edge Function: process-sighting-image
--------------------------------------
Deploy (either method):

  supabase functions deploy process-sighting-image

  Or Supabase MCP: deploy_edge_function (name process-sighting-image, verify_jwt true).
  WebP pipeline: npm:@imagemagick/magick-wasm@0.0.34 + magick.wasm via import.meta.resolve
  (see supabase/functions/process-sighting-image/_shared/imagePipeline.ts).

Config: supabase/config.toml sets verify_jwt = true for this function (maintainer
session required for file/URL upload modes).

Modes:
  - Multipart POST: file + ymd + optional mediaId (browser uploads after client resize)
  - JSON POST: { sourceUrl, ymd, mediaId? } (admin URL submit, review approve from external URL)

Imgur: when sourceUrl is i.imgur.com, the function fetches via IMGUR_PROXY_* (Cloudflare
Worker, US egress) instead of direct Imgur. Browser previews use the same worker via
js/imgurProxy.js. Setup: docs/cloudflare-imgur-proxy-setup.md.

Limits: Edge has ~256MB RAM and short CPU time per request. Client pre-resizes files
to ≤1920px before upload. URL fetches are capped at 12MB. WebP encode uses
@imagemagick/magick-wasm@0.0.34 (same pattern as Supabase image-manipulation example).

iOS Safari: browsers do not encode WebP from canvas; all WebP encoding is server-side.

Local backup: npm run backup:images
  Writes storage-backup/sightings-YYYY-MM-DD.json and sightings-images-YYYY-MM-DD/.

Database webhook: new public submission
---------------------------------------
Dashboard → Database → Webhooks → Create:

  Table:   public.sighting_submissions
  Events:  Insert
  Target:  Edge Function notify-new-submission

Set DISCORD_WEBHOOK_URL before testing. Submit via /submit to verify one Discord message
per row with link /review?id=<submission_id>.
