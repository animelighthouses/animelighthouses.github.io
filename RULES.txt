Submission Rules

---

1. Lighthouse Logic

IF lighthouse_type = "real":
  lighthouse_id MUST exist

IF lighthouse_type = "fictional":
  lighthouse_id MUST be null

---

2. Title Requirements

- title_r MUST exist
- title_jp MUST exist
- title_en MUST exist (fallback to title_r)

---

3. Image Format

- ["images/<filename>"]

---

4. Media Consistency

- media_type must match AniList URL

---

5. Submission

- Empty fields converted to null
- Auth required

---

6. Philosophy

- Validation handled in frontend
- Database is permissive
