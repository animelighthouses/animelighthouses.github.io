Anime Lighthouse Index

---

A small web app for tracking lighthouse appearances in anime and manga.

---

Features:
- Browse recent sightings (public)
- Comprehensive index view (public)
- Search and filter (public)
- Submit new real lighthouses and sightings (unlisted)

---

Tech:
- Vanilla JS
- Supabase
- AniList API

---

Purpose:
Structured dataset + exploration tool
